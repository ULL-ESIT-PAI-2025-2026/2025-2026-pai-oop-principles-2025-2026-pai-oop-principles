## Introduction
This repository focuses on OOP concepts and style guide, good programming practices, clean code and code smells using **Typescript**.
This includes:
- Coding examples 
- Presentation slides

This directory is organised as follows:
```
      .
      ├── bib          # Presentation bibliography and references
      ├── slides       # slides of the presentation 
      ├── src          # Source code 
           ├ clean_code
           ├ code_smells
           ├ good_practices
           ├ google_style_guide
           ├ no_comments_version
           ├ oop-concepts
```
